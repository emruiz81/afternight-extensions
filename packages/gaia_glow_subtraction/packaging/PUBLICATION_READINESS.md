# Gaia Glow Subtraction Publication Readiness

Status: source-staged as `gaia_glow_subtraction` version `0.1.0`; not
published.

## Completed Gates

- Package layout: manifest, entry point, GPL-3.0-or-later `LICENSE`,
  `THIRD_PARTY_NOTICES.md` (ported source, Python dependencies, catalogue
  data), `UPSTREAM.md` and `UPSTREAM.json`.
- Provenance: `tools/check_upstream.py` verifies the captured Siril scripts
  baseline, and the vendoring test holds `gaia_glow_subtraction_core.py` to the
  upstream text.
- Dependencies: `package/requirements.lock` pins twelve PyPI distributions
  with Windows and Linux wheel hashes for CPython 3.14, generated by
  `packaging/refresh_requirements_lock.py`; it installs with
  `pip install --no-deps --require-hashes`.
- Automated checks: package tests cover the adapter (typed headers from raw
  cards, keywords, HISTORY, detections without a flip, channel layouts, the
  cache folder) and run the vendored pipeline end to end on synthetic
  plate-solved fields with the network blocked: the in-frame fallback and a
  catalogue run (astrometric match below 0.5 px, calibration on the field's
  stars) each remove most of the glow around bright stars; integer images keep
  their sample type; a second subtraction is refused unless forced;
  cancellation, an unsolved image, the glow-model output and the PSF file are
  covered.

## Open Gates

- Representative real-image visual QA in AfterNight on plate-solved stacks
  with bright stars (for example M45, M42 with Alnitak), mono and colour, with
  the remote Gaia catalogue downloaded and cached.
- Host check: AfterNight's star finder on real stacks gives enough detections
  for the astrometric check, the private environment installs from the lock on
  both runtime targets, and a run's progress and cancel work in the process
  window.
- Release signoff, then a `repository.json` release entry with
  `asset_base_url`, removal of `"publish": false`, and the package id in the
  publish workflow's dropdown.
